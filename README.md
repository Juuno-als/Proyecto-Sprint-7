# Proyecto-Sprint-7

Aplicación web desarrollada con Streamlit para realizar un análisis exploratorio básico de un conjunto de datos de anuncios de venta de vehículos usados.

La aplicación permite al usuario generar:
- Un histograma del odómetro
- Un gráfico de dispersión entre precio y odómetro

Las visualizaciones fueron creadas con Plotly y la app está preparada para ser desplegada en Render.
